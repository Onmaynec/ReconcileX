# Матрица реализации PV-FIN-03

Инженерный статус на версии 0.1.0. Выпуск не означает успешной приёмки всех Must.

## Реализовано

FIN-F-01…05: профиль CSV/XLSX, валидирующий preview, SHA-256, natural key, оригинал + normalized record, integer minor units.

FIN-F-07…13: версии и приоритеты правил, автоматическая 1:1 при единственном кандидате, отказ от неоднозначного выбора, ручные группы n:1/1:n, active unique index, версия правила и след объяснения, повтор job не обновляет подтверждённую группу.

FIN-F-15…18: комментарий и автор ручной группы, независимый controller, блокировки и уникальные ограничения, отмена отдельным аудит-событием.

FIN-F-19…22: сводные цифры по источнику, snapshot периода, неизменяемый финансовый отчёт, экспорт CSV с проверкой доступа.

Есть REST API, пять ролей, PostgreSQL-миграция, MinIO, job-таблица, отдельный worker, Docker Compose, базовые интеграционные тесты.

## Частично и не проверено

- FIN-F-06: генерация шести синтетических форматов предусмотрена, но полный импорт 150000 строк в три периода в CI ещё не проверен.
- FIN-F-14: unmatched, ambiguous, amount_mismatch; duplicate и wrong_currency сейчас отклоняются валидацией и не оформлены как самостоятельные ReconcileIssue.
- AT-01…AT-12: тесты присутствуют для основного сценария, но AT-07 пока проверяет только запрет согласования оператором, а AT-09 — повтор idempotency key без настоящего убийства worker.
- HTTP 429 и распределённое ограничение частоты запросов — не реализованы.
- Конфигурация продакшен-TLS, backup scheduler, централизованные JSON-логи, метрики p50/p95, отчёт нагрузочного тестирования, восстановление оригиналов по checksum требуют дальнейшей работы.
- Возможны ограничения обработки крупных периодов из-за одной транзакции на job.
